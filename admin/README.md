# لوحة تحكم الموقع — دليل الاستخدام

اللوحة تتحكم في محتوى موقعك (`index.html` المنشور على GitHub Pages) **دون لمس الكود**.
كل النصوص (الإنجليزية والعربية والصينية) والروابط والأسعار وصور الأعمال تُحرَّر من مكان واحد.

## التشغيل محليًا

```bash
npm run dev
```

- الموقع: `http://localhost:7100/`
- اللوحة: `http://localhost:7100/admin/`
- لتغيير المنفذ: `npm run dev -- --port 8000`

> لا تفتح اللوحة بملف `file://` مباشرة — تحتاج خادمًا محليًا حتى تستطيع قراءة ملفات الموقع.

## طريقة العمل

1. عدّل أي حقل — تُحفظ المسودة تلقائيًا في متصفحك (localStorage) ويظهر شريط «تغييرات غير منشورة».
2. **المعاينة الحية**: زر «المعاينة الحية» يفتح الموقع بجانب اللوحة ويتحدث أثناء الكتابة.
3. **النشر**: زر «نشر إلى GitHub» يرفع `content.json` إلى المستودع مباشرة — يتحدث الموقع خلال دقيقة تقريبًا.

## النشر إلى GitHub (أول مرة فقط)

1. افتح https://github.com/settings/personal-access-tokens/new
2. أنشئ **Fine-grained token**:
   - Repository access: فقط `abdallamaher1993/hermes-agent`
   - Permissions: **Contents → Read & Write**
   - الصلاحية: 90 يومًا أو أطول
3. انسخ الرمز (`github_pat_…`) والصقه في نافذة النشر باللوحة — يُحفظ في متصفحك فقط.

## كيف يعمل النظام

| الملف | الدور |
|---|---|
| `content.json` (جذر المستودع) | **مصدر المحتوى الحقيقي** — يقرأه الموقع عند كل زيارة |
| `js/i18n.js` | القيم الافتراضية (احتياطي إذا غاب content.json) |
| `js/content-loader.js` | يطبّق content.json على الصفحة (نصوص + روابط + أسعار + صور) |
| `admin/` | هذه اللوحة — لا تؤثر على ظهور الموقع للزوار |

## ملاحظات

- **واتساب**: أضف رابط `https://wa.me/…` في «بيانات الموقع والروابط» وسيظهر تلقائيًا في قسم التواصل. اتركه فارغًا لإخفائه.
- **تغيير الصور**: ارفع الصورة الجديدة إلى مجلد `img/` في المستودع (يدويًا أو عبر وكيل)، ثم اكتب مسارها في حقل المشروع.
- **Webhook الطلبات**: رابط استقبال نموذج «اطلب الآن» يُعدَّل من «بيانات الموقع والروابط».
- صفحتا `about.html` و`project.html` تلتزمان بالنصوص المترجمة أيضًا، لكن محرّر اللوحة يركّز على الصفحة الرئيسية.
- اللوحة على `/admin/` **عامة الظهور** (لا يمكن حماية صفحة ثابتة) — لكن لا يمكن لأحد النشر بدون رمز GitHub الخاص بك، والرمز لا يغادر متصفحك. أُضيفت `noindex` و`Disallow` في robots.
